🚆 Railway Reservation App

An Android app built with Java and SQLite that lets users search trains, book tickets, and manage reservations effortlessly — all with a smooth, user-friendly interface and offline database support.

✨ Features

🔍 Search trains by source and destination stations

🗓️ View train schedules 

🎫 Book railway tickets with passenger details

❌ Cancel booked tickets easily

📜 View booking history at any time

💾 Data stored locally using SQLite for offline access

🎨 Clean and intuitive UI for a smooth user experience
